# 台灣外傷醫學會專科考題（95–114 年）

純靜態、可離線使用的練習網站。把整個資料夾或壓縮檔傳給同仁，用瀏覽器開啟 `index.html` 即可，不必架設伺服器。

題庫共 1006 題（95–114 年，18 個主題）。詳解為學習輔助整理，並非官方解答；考試與臨床請以官方公布答案及最新指引為準。

## 直接開啟

解壓縮後，以瀏覽器開啟 `index.html`（雙擊或用「開啟檔案」）。`file://` 離線也可使用，不需網路。

建議使用最新版 Chrome、Edge、Firefox 或 Safari。

## 免費線上分享（可選）

若希望用網址分享，可把 **本資料夾的內容**（須包含 `index.html`、`css/`、`js/`、`data/`、`media/`）上傳到任一靜態網站託管：

1. **Netlify Drop**  
   開啟 [https://app.netlify.com/drop](https://app.netlify.com/drop)，把整個資料夾拖進去即可得到一個公開網址，不必註冊也可先試用。

2. **Cloudflare Pages**  
   登入 Cloudflare，建立 Pages 專案後，選擇「直接上傳」並上傳本資料夾。

3. **GitHub Pages**  
   建立一個公開儲存庫，將本資料夾內容放在儲存庫根目錄（或 `docs/`），在 Settings → Pages 選擇對應分支與資料夾後發布。

本站沒有使用需要網路的 CDN，因此部署後即使關掉外網腳本，頁面本身仍可運作。
